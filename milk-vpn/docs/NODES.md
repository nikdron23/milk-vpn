# Подготовка VPN-серверов (3x-ui)

Один VPS = одна страна = одна панель 3x-ui. Сколько серверов вы добавите в админке — столько локаций увидят пользователи.

## 1. Арендуйте VPS

- Ubuntu 22.04/24.04, от 1 vCPU / 512 МБ–1 ГБ ОЗУ; канал — чем шире, тем лучше.
- Выбирайте страну под нужные локации (Нидерланды, Германия, Финляндия и т. п.).
- Порт **443/tcp** на этом VPS должен быть свободен — на нём будет работать VPN.

## 2. Установите 3x-ui

Зайдите на VPS по SSH и запустите (скрипт лежит в проекте, `deploy/install-node.sh`):

```bash
sudo bash install-node.sh
```

Он запускает **официальный установщик** 3x-ui. Установщик выдаст:
- адрес панели **вместе с секретным путём** — вида `https://IP:порт/секретный_путь`;
- логин и пароль.

**Запишите их** — понадобятся в админке Milk VPN. Двухфакторную аутентификацию в панели не включайте (API-вход с кодом не поддерживается).

Если у вас включён файрвол (`ufw`), откройте порт панели и 443:
```bash
ufw allow 443/tcp
ufw allow ПОРТ_ПАНЕЛИ/tcp
```

## 3. Создайте inbound VLESS + Reality

Откройте панель в браузере → **Inbounds → Add Inbound** и заполните:

| Поле | Значение |
|---|---|
| Remark | любое, например `main` |
| Protocol | **vless** |
| Port | **443** |
| Transmission | **tcp** |
| Security | **reality** |
| uTLS | `chrome` |
| Dest / SNI (serverNames) | популярный сайт с TLS 1.3, например `www.microsoft.com:443` / `www.microsoft.com` |
| Private/Public key | нажмите **Get New Cert** |
| Short IDs | оставьте автоматически созданные |

Клиентов добавлять **не нужно** — их создаёт Milk VPN. Сохраните inbound и запомните его **ID** (колонка ID в списке inbound-ов; для первого inbound это обычно `1`).

## 4. Добавьте сервер в админке Milk VPN

«Серверы» → «Добавить сервер»:

| Поле | Что писать |
|---|---|
| Название | то, что увидят пользователи, например `Нидерланды · Амстердам` |
| Страна | выберите — появится флаг |
| Адрес панели | `https://IP:порт/секретный_путь` (без слэша в конце) |
| Логин / пароль | от панели 3x-ui |
| ID inbound | номер inbound-а из шага 3 |
| Flow | `xtls-rprx-vision` (для VLESS + Reality + TCP) |
| Домен или IP сервера | куда подключаются клиенты (домен ноды или её IP); пусто — возьмётся из адреса панели |
| Проверять TLS | снимите галочку, если панель открывается по IP с самоподписанным сертификатом |

После сохранения проверьте статус: «онлайн».

## Как это работает

- При выдаче ключа Milk VPN создаёт клиента (с одним и тем же UUID) **на всех включённых серверах** и ставит срок/лимиты по тарифу.
- Пользователю отдаётся ссылка-подписка `https://ВАШ_ДОМЕН/sub/...`: приложение получает список всех локаций и обновляет его само.
- Новый сервер — все действующие ключи добавляются на него автоматически.
- Отключили сервер — он пропадает из подписок, клиенты на самой панели не удаляются.
- Если одна из нод недоступна, выдача ключа всё равно проходит на остальных; недостающее досинхронизируется позже.

## Ограничения

- Поддерживается **VLESS** (inbound других протоколов в подписку не попадёт).
- Лимит трафика тарифа действует **на каждом сервере отдельно** (на 3 серверах пользователь теоретически получит до 3 × лимит). Для безлимитных тарифов это не важно.
- Лимит устройств (`limit ip`) также считается каждой панелью отдельно.
- Встроенная подписка 3x-ui не используется — Milk VPN отдаёт свою, объединённую.
