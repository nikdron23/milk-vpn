# Работа с админ-панелью

Адрес: `https://ВАШ_ДОМЕН/admin`. Логин и пароль — из `.env` (`ADMIN_LOGIN`, `ADMIN_PASSWORD`). Вход ограничен: 5 неверных попыток с одного IP — блокировка на 5 минут.

## Разделы

| Раздел | Что можно делать |
|---|---|
| **Обзор** | пользователи, активные ключи, выручка (всего и за 30 дней), статус каждого VPN-сервера, последние заказы |
| **Серверы** | добавлять/изменять/отключать/удалять VPN-серверы по странам, проверять связь, синхронизировать ключи |
| **Заказы** | история; кнопка «Выдать вручную» для оплаченных заказов, по которым ключ не выдался |
| **Ключи** | фильтры (активные/истёкшие/отозванные), продление на N дней, отзыв; колонка «Серверы» показывает, на скольких серверах создан ключ |
| **Пользователи** | поиск по Telegram ID/нику/имени; карточка: ключи, заказы, кто пригласил, сколько привёл; блокировка; бесплатная выдача ключа |
| **Тарифы** | название, срок, трафик (0 — безлимит), число устройств, цена, порядок, активность |
| **Рефералка** | настройки реферальной программы и пробного периода + статистика и топ приглашающих |
| **Рассылка** | сообщение всем пользователям бота (поддерживается HTML-разметка Telegram) |

## Реферальная программа («Приведи друга»)

Каждый пользователь получает личную ссылку `https://t.me/ВАШ_БОТ?start=r_КОД` (в боте — кнопка «👥 Пригласить друга», в кабинете — блок «Приведи друга»).

Настройки (раздел «Рефералка», применяются сразу):

| Настройка | Смысл |
|---|---|
| Программа включена | выключатель всей системы (кнопки в боте/кабинете и блок на сайте скрываются) |
| Награда пригласившему, дней | сколько дней добавляется к ключу пригласившего |
| Бонус приглашённому, дней | сколько дней друг получает к своей **первой** покупке |
| Максимум наград на одного | ограничение, сколько раз можно получить награду (0 — без лимита) |
| Только за первую оплату | если включено — награда один раз за каждого друга; иначе — за каждую его оплату |

Правила:
- Привязка к пригласившему происходит **только при первом запуске бота** новым пользователем по реферальной ссылке. Уже зарегистрированного пользователя привязать нельзя. Самого себя пригласить нельзя.
- Награда начисляется **только после реальной оплаты** друга (регистрация награды не даёт) и записывается в статистику.
- Бонусные дни добавляются к самому свежему ключу пригласившего. Если ключа нет — дождутся его первой покупки; если серверы недоступны — применятся фоновой задачей.

## Пробный период

Там же («Рефералка» → «Пробный период»): длительность в днях (0 — отключить) и лимит трафика. Выдаётся один раз на аккаунт.

## Тарифы

- Неактивный тариф скрыт от покупателей, но уже выданные ключи работают.
- Самый выгодный по цене за день тариф на сайте автоматически помечается «Выгоднее всего».
- Тарифы по умолчанию создаются при первом запуске — отредактируйте цены под себя.

## Серверы

Подробно — [NODES.md](NODES.md). Коротко:
- **Отключить** — сервер пропадает из подписок (клиенты на панели остаются).
- **Синхронизировать** — добавить на сервер ключи, которых там ещё нет.
- **Удалить** — убрать из списка (на самой панели ничего не удаляется).
- Пароль панели хранится в зашифрованном виде (ключ — из `SECRET_KEY`).

## Команды бота для администраторов

Для Telegram ID из `ADMIN_TG_IDS`: `/admin` — ссылка на панель, `/stats` — краткая статистика.

## Изменение внешнего вида и текстов

- Тексты лендинга: `app/templates/landing.html`, инструкция: `app/templates/setup.html`, юридические страницы: `terms.html`, `privacy.html`.
- Цвета и оформление: переменные в начале `app/static/style.css`.
- После правки файлов на сервере: `./deploy/update.sh`.
